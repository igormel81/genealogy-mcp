# genealogy-mcp — история вашей семьи с любым ИИ-ассистентом

**[English version](README.md)**

[![CI](https://github.com/igormel81/genealogy-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/igormel81/genealogy-mcp/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

[MCP](https://modelcontextprotocol.io)-сервер, который превращает Claude, ChatGPT, Cursor или любой ассистент с
поддержкой MCP во внимательного генеалога. Он знает, **где** лежат записи о ваших предках (79 архивов и баз по России и
бывшему СССР, Европе, Британии, США и Латинской Америке), **как** в них искать (варианты имён, транслитерация, старая
орфография, старый стиль) и **когда находка действительно о вашем человеке** — поэтому ассистент даёт рабочие ссылки и
план, а не уверенные догадки.

Сделан на опыте настоящего поиска для открытого семейного архива на движке
[gene_archive](https://github.com/igormel81/gene_archive): метрические книги, ревизские сказки, базы Первой мировой и
Великой Отечественной, следственные дела, эмиграция — и все ловушки, в которые мы попадали.

## Что можно спросить

> *Прадед, Иван Колодин, родился около 1885 г. под Богородицком Тульской губернии. Где искать?*

Ассистент составит план для России 1880–1945 гг., прочитает руководства по видам документов, соберёт формы имени
(Колодин / Колодина / Колодинъ / Kolodin / Kołodin…), даст ссылки на поиск в FamilySearch, полнотекстовый поиск
Internet Archive и военные базы, подскажет, в каком архиве метрики, и составит запрос.

> *Это тот же Иван? В записи о крещении «Іоаннъ, отец Петръ, 1887, Сынково».*

`check_match` сравнит факт за фактом с учётом вариантов имён и «гуляющего» возраста: два независимых совпадения кроме
имени — подтверждено; одно — вероятно; противоречие — нужен третий документ.

> *Кем мне приходится дочь двоюродного брата бабушки?*

`kinship` → по-русски, по-английски и по-румынски, с ожидаемой долей общей ДНК.

> *Проверь моё древо.* (GEDCOM из MyHeritage, Ancestry, Gramps, Geni…)

`audit_tree` найдёт невозможное (родился после смерти матери, матери 10 лет, смерть раньше рождения), возможные
дубли и пробелы — список задач для следующего поиска.

## Зачем он нужен

| Без него | С genealogy-mcp |
|---|---|
| Ассистент называет два-три известных сайта | 79 источников по стране, годам и виду документов, к каждому — «как искать с толком» |
| Ищет одно написание | Варианты написания, дореформенная орфография, мужская и женская формы, 9 систем транслитерации, соответствия имён (Иван = Іоаннъ = Jan = Johann = Juan) |
| Выдуманные или битые адреса | Готовые ссылки на поиск по проверенным шаблонам; сайты проверяются каждую неделю |
| «Вероятно, это ваш предок» | Явное правило доказательства: однофамилец — не родственник |
| Даты как написано | Старый ↔ новый стиль, год рождения по возрасту с реальным разбросом, даты в формате GEDCOM |
| Общие советы | Руководства: метрики, исповедные ведомости, ревизские сказки, похозяйственные книги, Первая мировая и ВОВ, следственные дела, списки пассажиров, переписи, гражданская регистрация в Европе, Латинская Америка |
| Письмо в архив с нуля | Черновики запросов в ЗАГС, госархив, ЦАМО, архив ФСБ — и в любой архив по-английски, по-испански, по-португальски |

Всё работает на вашем компьютере. Сервер не ходит в сеть: не видит ваших поисков и ничего никуда не отправляет.

## Установка

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/) — он сам скачает Python и пакет.

**Claude Desktop** — «Настройки → Developer → Edit Config», добавьте:

```json
{
  "mcpServers": {
    "genealogy": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/igormel81/genealogy-mcp", "genealogy-mcp"]
    }
  }
}
```

**Claude Code:**

```sh
claude mcp add genealogy -- uvx --from git+https://github.com/igormel81/genealogy-mcp genealogy-mcp
```

**Cursor** (`~/.cursor/mcp.json`), **Windsurf**, **Cline** — тот же блок `mcpServers`.
**VS Code** (`.vscode/mcp.json`): `{"servers": {"genealogy": {"command": "uvx", "args": [ …то же… ]}}}`.

**Клиенты, подключающиеся по HTTP** (коннекторы ChatGPT, удалённые агенты): запустите
`genealogy-mcp --http --host 0.0.0.0 --port 8000` за HTTPS и добавьте адрес `https://ваш-сервер/mcp`.
В этом режиме `audit_tree` принимает только текст GEDCOM, а не путь к файлу.

Когда пакет появится на PyPI, хватит `uvx genealogy-mcp`.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `plan_research` | План поиска для страны и периода: какие документы есть, руководства, источники по порядку |
| `find_sources` | Источники по стране или региону (`europe`, `latin_america`, «Российская империя»…), годам и виду записей |
| `source_details` | Всё об одном источнике: охват, доступ, как искать |
| `search_links` | Готовые ссылки на поиск по имени и его вариантам |
| `name_variants` | Варианты написания, старая орфография, мужская/женская форма, транслитерации, соответствия имён, отчества |
| `normalize_date` | «около 1899», «9 октября 1899 г.» → `ABT 1899`, `9 OCT 1899` |
| `convert_calendar` | Старый ↔ новый стиль |
| `birth_year_from_age` | Годы рождения по возрасту в документе |
| `kinship` | Название родства по-русски, по-английски и по-румынски, с долей общей ДНК |
| `check_match` | Наш ли человек в найденной записи? Вердикт и сравнение по каждому факту |
| `audit_tree` | Невозможные факты, дубли и пробелы в GEDCOM или `family_tree.json` |
| `draft_archive_request` | Черновик запроса в ЗАГС или архив |
| `record_guide` | Как читать и где искать вид документов |
| `glossary` | Старинные термины из документов: сословия, свойство, фонд/опись/дело |

**Ресурсы:** `genealogy://sources` (каталог), `genealogy://guide/research/{en|ru}` (полное руководство по поиску),
`genealogy://guide/prompts/{en|ru}` (готовые запросы к ассистенту для каждого шага), `genealogy://records/{тема}`,
`genealogy://glossary`. **Шаблоны (prompts):** начать поиск, проверить находку, расшифровать запись, написать в архив.

## Приватность и честность

- С вашего компьютера ничего не уходит: у сервера нет сетевого кода. Ассистент, которым вы пользуетесь, — отдельный
  сервис со своими правилами; подумайте, прежде чем вставлять сведения о живых людях.
- Письма — черновики: проверяете и отправляете вы.
- Правила для ассистента: ссылаться на подлинник, хранить противоречащие версии, помечать догадки как «вероятно»,
  не связывать однофамильца без доказательств.
