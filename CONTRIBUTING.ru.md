# Как помочь

[English version](CONTRIBUTING.md)

Предложите источник, сообщите о неработающей ссылке или ошибке через формы задач на GitHub либо пришлите pull request. Также можно дополнять руководства по документам и варианты имён.

## Добавить источник

Правьте `tools/make_sources.py` — исходник каталога. Добавьте вызов `add()` рядом с похожими источниками. Не редактируйте сгенерированный `src/genealogy_mcp/data/sources.json` вручную.

```python
add(id, name, url, countries, years, records, access,
    about, about_ru, how, how_ru, search=None)
```

Все поля, кроме `search`, обязательны:

| Поле | Значение |
| --- | --- |
| `id` | Уникальный постоянный идентификатор; следуйте существующим примерам: строчные буквы и подчёркивания. |
| `name` | Название архива или базы. |
| `url` | Основной адрес каталога или базы. |
| `countries` | Заглавные двухбуквенные коды ISO 3166-1 alpha-2 через пробел: например, `"RU UA BY"`, `"US"`, `"GB"`; `"*"` — весь мир. Для исторических территорий используйте современные коды. |
| `years` | Кортеж границ периода включительно `(year_from, year_to)`, например `(1800, 1920)`. |
| `records` | Ключи из `RECORD_KINDS` в `src/genealogy_mcp/sources.py` через пробел. |
| `access` | `free` — бесплатно; `free_account` — бесплатно, нужен вход; `paid` — платно; `request` — по запросу, письмом или при посещении; `mixed` — частично бесплатно. |
| `about`, `about_ru` | Описание источника и его охвата по-английски и по-русски. |
| `how`, `how_ru` | Практическая инструкция поиска на обоих языках: индексы и снимки, язык, ограничения и особенности. |
| `search` | Необязательный шаблон ссылки поиска; пропустите, если прямой ссылки нет. |

Текущие ключи видов записей: `church`, `vital`, `census`, `revision`, `confession`, `household`, `military`, `repression`, `deportation`, `holocaust`, `forced_labour`, `displaced`, `emigration`, `newspapers`, `directories`, `books`, `graves`, `trees`, `catalogs`, `places`, `maps`, `clergy`, `nobility`. Значения и актуальный список смотрите в `RECORD_KINDS`.

Шаблон поиска поддерживает `{given}`, `{surname}`, `{year_from}`, `{year_to}`, `{place}`, `{q}`. Используйте только параметры, поддерживаемые источником, например:

```text
https://example.org/search?given={given}&surname={surname}&from={year_from}&to={year_to}&place={place}&q={q}
```

Сервер кодирует подставляемые значения для URL и удаляет пустые параметры запроса. Если `q` не задан, он составляется из имени, фамилии и места.

Пересоберите каталог и включите в pull request изменения генератора и полученный JSON:

```sh
python3 tools/make_sources.py
```

Не добавляйте сайты, нарушающие авторские права или продающие персональные данные. Точно описывайте ограничения доступа; не публикуйте данные входа и частные семейные документы в задачах и pull request.

## Запустить проверки

Нужен Python 3.10 или новее. Из корня репозитория создайте и активируйте виртуальное окружение, затем установите пакет и проверку:

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install . pyflakes
python3 -m unittest discover tests
pyflakes src tests tools
```

Перед отправкой просмотрите diff и объясните изменения. Если менялся каталог, отметьте запуск генератора и тестов в шаблоне pull request.
